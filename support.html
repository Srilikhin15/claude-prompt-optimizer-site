Contact Support

What to include in your request

  • A short description of the issue.
  • The steps that led to the issue.
  • What you expected and what happened instead.
  • A sanitized example prompt, if necessary and safe to share.

What this plugin supports

Claude Prompt Optimizer helps improve the clarity and structure of prompts for Claude. It does not connect to your Claude account, call the Claude API, or provide exact Claude token counts.

Please do not send passwords, API keys, authentication codes, or unnecessary confidential information in support requests.

Claude Prompt Optimizer is an independent project and is not affiliated with or endorsed by Anthropic.
